# Мова Нанова — адкрыццё сезона

Прэзентацыя для адкрыцця сезона «Мова Нанова» ва Уроцлаве.
Тэма: філаматы, філарэты і прамяністыя + творчая майстэрня.

## Як паказваць

Адкрыйце `index.html` у Chrome або Safari і націсніце **F** (на ўвесь экран).

Файл `Філаматы і філарэты.mp4` мусіць ляжаць у той жа папцы — слайд 7 прайграе яго па кліку.

## Кіраванне

| Клавіша | Дзеянне |
| --- | --- |
| `→` `↓` `PageDown` `прабел` | наступны слайд |
| `←` `↑` `PageUp` | папярэдні слайд |
| `Home` / `End` | першы / апошні слайд |
| `F` | на ўвесь экран |
| `B` | чорны экран |

### Слайд з відэа

На слайдзе з відэа тыя самыя клавішы кіруюць прайграваннем, каб усё рабілася
з прэзентацыйнага клікера і да яго не трэба было падыходзіць да ноўтбука:

| Націск на клікеры | Дзеянне |
| --- | --- |
| **далей** | прайграць відэа |
| **далей** двойчы | наступны слайд |
| **назад** | паўза |
| **назад** двойчы | перамотка на пачатак |

Калі відэа яшчэ не запускалі або яно стаіць на паўзе, адзін націск **назад**
вяртае на папярэдні слайд — каб са слайда заўсёды можна было выйсці назад.

Акно для падвойнага націску — 420 мс. Мышшу відэа па-ранейшаму запускаецца
і спыняецца простым клікам, а кнопкі ‹ › унізе заўсёды гартаюць слайды.

Працуюць таксама прэзентацыйныя клікеры, свайп на тачскрыне, кнопкі ‹ › унізе
і сегментаваная паласа прагрэсу зверху (клік па сегменце — пераход на слайд).

Спасылка `index.html#8` адкрывае адразу восьмы слайд.

## Конкурс ад пляцоўкі

Слайд 2 — конкурс ад Pałac Borowa (прыз: начлег у палацы са сняданкам).
На слайдзе ёсць QR-код на старонку палаца ў Google Maps для водгуку;
код згенераваны лакальна і ўбудаваны ў файл, інтэрнэт для паказу не патрэбны.

Фота палаца — з афіцыйнага сайта palacborowa.net.

## Тэхнічнае

- Адзін самадастатковы файл: шрыфт Inter і ўсе выявы ўбудаваныя як data URI, інтэрнэт не патрэбны.
- Фіксаваная сцэна 1920×1080 маштабуецца пад любы экран, таму на праектарах 4:3 і 16:10 макет не «плыве».
- Разлічана на паказ праз праектар (экран ~2×2 м, зала на ~70 чалавек): мінімальны кегль тэксту 34–38 px пры 1920×1080.
