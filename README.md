# Мова Нанова — адкрыццё сезона

Прэзентацыя для адкрыцця сезона «Мова Нанова» ва Уроцлаве.
Тэма: філаматы, філарэты і прамяністыя + творчая майстэрня.

## Як паказваць

Адкрыйце `index.html` у Chrome або Safari і націсніце **F** (на ўвесь экран).

Файл `Філаматы і філарэты.mp4` мусіць ляжаць у той жа папцы — слайд 6 прайграе яго па кліку.

## Кіраванне

| Клавіша | Дзеянне |
| --- | --- |
| `→` `↓` `PageDown` `прабел` | наступны слайд |
| `←` `↑` `PageUp` | папярэдні слайд |
| `прабел` на слайдзе з відэа | прайграць / паўза |
| `Home` / `End` | першы / апошні слайд |
| `F` | на ўвесь экран |
| `B` | чорны экран |

Працуюць таксама прэзентацыйныя клікеры, свайп на тачскрыне, кнопкі ‹ › унізе
і сегментаваная паласа прагрэсу зверху (клік па сегменце — пераход на слайд).

Спасылка `index.html#7` адкрывае адразу патрэбны слайд.

## Тэхнічнае

- Адзін самадастатковы файл: шрыфт Inter і ўсе выявы ўбудаваныя як data URI, інтэрнэт не патрэбны.
- Фіксаваная сцэна 1920×1080 маштабуецца пад любы экран, таму на праектарах 4:3 і 16:10 макет не «плыве».
- Разлічана на паказ праз праектар (экран ~2×2 м, зала на ~70 чалавек): мінімальны кегль тэксту 34–38 px пры 1920×1080.

- `mova_nanova_presentation_final (2).html` — першапачатковая версія (архіў).
